# ☕ Velvet Brew – Café & Restaurant Website

A modern, elegant, and fully responsive café & restaurant website built with Next.js, TypeScript, and Tailwind CSS. The project showcases a premium dining experience with beautifully designed sections, smooth animations, menu highlights, customer testimonials, reservation forms, and gallery displays.

## 🚀 Live Demo

https://cafe-restaurant-web-development.vercel.app/

---

## ✨ Features

* Modern and premium restaurant UI
* Fully responsive design
* Hero section with engaging visuals
* Featured specials showcase
* Interactive menu section
* Chef's special highlights
* Customer testimonials
* Reservation booking section
* Restaurant gallery
* Contact information section
* Loading and custom error pages
* SEO-friendly configuration
* Sitemap and Robots.txt included
* Smooth animations and transitions
* Optimized performance using Next.js
